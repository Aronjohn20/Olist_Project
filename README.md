# Olist Analytics Engineering Platform

## Project Status

Phase 1 — Requirements Gathering

## Business Problem

The marketplace has a large number of sellers, but does not have a centralized analytical system to identify high-performing and underperforming sellers or understand the factors affecting seller performance.

Marketplace managers currently need to combine information from different sources to evaluate seller performance.

## Objective

Build an analytics engineering platform that combines marketplace data to measure seller performance, identify underperforming sellers, and provide actionable insights to marketplace management.

## Planned Technology Stack

- Python
- PostgreSQL
- dbt
- Power BI
- GitHub

## Dataset

Olist Brazilian E-Commerce Public Dataset

## Project Approach

The project will follow a realistic analytics engineering lifecycle:

Problem → Requirements → System Design → Data Ingestion → Transformation → Data Quality → Analytics → BI → Testing → Deployment → Production Simulation → Scaling → Documentation
