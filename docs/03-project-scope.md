# Project Scope

## In Scope

The project will initially focus on:

- Seller performance analysis
- Marketplace operational analysis
- Sales performance
- Customer review performance
- Delivery performance
- Seller comparison
- Historical performance trends
- Data ingestion
- PostgreSQL data storage
- dbt-based transformation
- Data quality validation
- Business-ready analytical models
- Power BI analytics

## Out of Scope for the Initial Version

The following are not part of the initial scope:

- Real-time analytics
- Customer-facing applications
- Automated seller payouts
- Inventory management
- Order management
- Payment processing
- Full production-scale cloud infrastructure

These boundaries may change if stakeholder requirements justify expanding the scope.
